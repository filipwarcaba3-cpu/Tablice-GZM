Emulator SIP GZM 2.0 - wersja demonstracyjna
Windows: rozpakuj ZIP, uruchom start_windows.bat (Python 3 wymagany).
Render: build command: pip install -r requirements.txt ; start command: gunicorn app:app
Mapa, tablica i wybrana linia są połączone. Dane 904N są demonstracyjne, nie są aktualnym rozkładem GZM. Ruch pojazdu jest symulowany. Mapa wymaga internetu. Edycje zapisują się lokalnie w przeglądarce.
